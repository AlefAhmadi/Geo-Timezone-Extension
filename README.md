# 🌐 Geo & Timezone Changer

[![Manifest V3](https://img.shields.io/badge/Manifest-V3-2563eb?style=flat-square)](https://developer.chrome.com/docs/extensions/mv3/intro/)
[![Browsers](https://img.shields.io/badge/Chrome%20%7C%20Edge%20%7C%20Brave-Compatible-10b981?style=flat-square)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-gray?style=flat-square)](LICENSE)

افزونه سبک و قدرتمند مبتنی بر **Manifest V3** برای شبیه‌سازی موقعیت جغرافیایی GPS و منطقه زمانی (Timezone) در تمام وب‌سایت‌ها و اپلیکیشن‌های وب.

---

## ✨ قابلیت‌ها

- 📍 **جعل موقعیت GPS:** بازنویسی بومی `navigator.geolocation` (`getCurrentPosition` و `watchPosition`) با مختصات دلخواه.
- ⏰ **تغییر منطقه زمانی:** تنظیم دقیق IANA Timezone بر روی کلاس `Intl.DateTimeFormat` و متدهای اصلی `Date.prototype`.
- 🏙️ **انتخاب سریع شهرها:** شامل لیست آماده از شهرهای مهم دنیا (تهران، نیویورک، آمستردام، برلین، توکیو و...) به همراه امکان درج مختصات دستی.
- 🛡️ **پراکسی اختصاصی سایت (Kill Switch):** دامنه‌های دلخواه فقط با وصل بودن فیلترشکن (تونل WireGuard / OpenVPN یا پراکسی) باز می‌شوند؛ با قطع شدن فیلترشکن، آن سایت‌ها باز نمی‌شوند.
- 🔍 **تشخیص خودکار فیلترشکن و نشانگر IP:** افزونه آدرس تونل یا پراکسی محلی را خودش پیدا می‌کند و IP فعلی را با نقطه سبز / قرمز نشان می‌دهد.
- ⚡ **اعمال بدون وقفه:** دکمه رفرش آنی برگه برای مشاهده فوری تغییرات در سایت هدف.
- 🔒 **حفظ حریم خصوصی:** اجرای محلی در مرورگر. تنها درخواست‌های خارجی، بارگذاری فونت پنجره افزونه و (فقط با روشن بودن Kill Switch) پرسیدن IP عمومی از سرویس‌های تشخیص IP است.

## 🚀 راهنمای نصب (کمتر از ۱ دقیقه)

1. مخزن را کلون کنید یا فایل‌های پروژه را دانلود نمایید:
   ```bash
   git clone https://github.com/AlefAhmadi/Geo-Timezone-Extension.git
   ```
2. مرورگر خود (Chrome / Edge / Brave) را باز کرده و به آدرس `chrome://extensions` بروید.
3. در گوشه بالا سمت راست، گزینه **Developer mode** را فعال کنید.
4. روی دکمه **Load unpacked** کلیک کرده و پوشه پروژه را انتخاب کنید.

## 🛡️ پراکسی اختصاصی سایت (Kill Switch)

با این قابلیت، دامنه‌های انتخابی شما **فقط وقتی باز می‌شوند که فیلترشکن وصل باشد**. اگر فیلترشکن قطع شود، آن سایت‌ها با خطای اتصال پراکسی باز نمی‌شوند و درخواستی با IP واقعی شما فرستاده نمی‌شود.

دو نوع فیلترشکن پشتیبانی می‌شود:

| نوع | مثال | روش محافظت |
| --- | --- | --- |
| **تونل** | WireGuard، OpenVPN | مرورگر پیش از هر درخواست بررسی می‌کند که مسیر اینترنت سیستم از آدرس تونل می‌گذرد؛ اگر نه، درخواست فرستاده نمی‌شود. |
| **پراکسی** | v2ray، Clash، sing-box | دامنه‌ها فقط از پراکسی فیلترشکن عبور می‌کنند و مسیر مستقیم ندارند. |

### نحوه تنظیم

1. فیلترشکن را روشن کنید.
2. در پنجره افزونه، روی **«تنظیمات و ابزارهای پیشرفته ⚙️»** کلیک کنید تا باز شود.
3. دکمه **«🔍 تشخیص خودکار»** را بزنید. افزونه نوع فیلترشکن را پیدا می‌کند و فیلدها را پر می‌کند:
   - **تونل:** آدرس تونل (IP داخلی، مثل `10.8.0.2`) و IP عمومی فیلترشکن.
   - **پراکسی:** آدرس و پورت پراکسی محلی (مثل `127.0.0.1:10809`).
4. مقادیر را بررسی کنید. کشور کنار IP نشان می‌دهد که IP فیلترشکن ثبت شده است، نه IP اینترنت خودتان. همه فیلدها را می‌توانید دستی عوض کنید.
5. دامنه‌ها را وارد کنید (هر خط یک دامنه). وارد کردن `example.com` زیردامنه‌هایی مثل `api.example.com` را هم پوشش می‌دهد.
6. کلید بالای بخش را روشن کنید. پیام سبز یعنی مرورگر تنظیمات را پذیرفته است.

در حالت پراکسی، برای **بقیه سایت‌ها** یکی را انتخاب کنید:

- **اتصال مستقیم:** بقیه سایت‌ها بدون پراکسی باز می‌شوند.
- **از همین پراکسی؛ اگر قطع بود، مستقیم:** بقیه سایت‌ها هم از پراکسی می‌روند، ولی با قطع شدن آن مستقیم باز می‌شوند.

### نشانگر IP

وقتی قابلیت روشن است، IP فعلی شما با یک نقطه رنگی در پنجره افزونه نمایش داده می‌شود (حتی وقتی بخش پیشرفته بسته است):

| نقطه | معنی |
| --- | --- |
| 🟢 سبز | IP فعلی همان IP ثبت‌شده فیلترشکن است. |
| 🔴 قرمز | تونل قطع شده، IP عوض شده یا پراکسی پاسخ نمی‌دهد. روی آیکون افزونه هم علامت `!` قرمز می‌آید. |
| 🟡 زرد | تونل وصل است، ولی IP عمومی قابل بررسی نبود یا ثبت نشده است. |

- در حالت **تونل**، با قرمز شدن نقطه سایت‌های فهرست بسته می‌شوند. اگر عمداً سرور فیلترشکن را عوض کرده‌اید، دوباره «تشخیص خودکار» و ذخیره را بزنید.
- در حالت **پراکسی**، نقطه فقط نشانگر است: سایت‌های فهرست در هر حال فقط از پراکسی می‌روند. IP خروجی پراکسی بعد از اولین اتصال خودکار ثبت می‌شود.
- IP هر ۱ دقیقه در پس‌زمینه و هر ۵ ثانیه وقتی پنجره افزونه باز است بررسی می‌شود.

### نکات و محدودیت‌ها

- **قطع تونل فوری اثر می‌کند، تغییر IP عمومی با تأخیر:** بررسی آدرس تونل پیش از هر درخواست انجام می‌شود و تأخیر ندارد. اما تغییر IP عمومی فقط در بررسی دوره‌ای دیده می‌شود (حداکثر ۱ دقیقه). اگر آدرس تونل را خالی بگذارید، فقط همین بررسی دوره‌ای از شما محافظت می‌کند.
- **تونل باید مسیر اینترنت عمومی را پوشش دهد:** تشخیص تونل بر اساس مسیر سیستم به اینترنت است. اگر تونل شما فقط چند مقصد خاص را می‌پوشاند (Split Tunnel)، سایت‌های فهرست بسته می‌مانند.
- **سرویس‌های تشخیص IP:** برای نمایش IP عمومی، افزونه از این سرویس‌ها می‌پرسد (به ترتیب، تا یکی جواب بدهد): `1.1.1.1/cdn-cgi/trace`، `ipv4.icanhazip.com`، `api.ipify.org`، `checkip.amazonaws.com`. این درخواست‌ها فقط وقتی فرستاده می‌شوند که Kill Switch روشن باشد یا «تشخیص خودکار» را بزنید.
- **تشخیص خودکار پراکسی:** فقط پورت‌های پیش‌فرض برنامه‌های رایج روی `127.0.0.1` بررسی می‌شود و فقط پراکسی‌های HTTP / Mixed قابل تشخیص‌اند. پراکسی فقط-SOCKS یا پورت غیرپیش‌فرض را دستی وارد کنید.
- **تشخیص خودکار تونل:** برای خواندن آدرس تونل، افزونه برای لحظه‌ای تنظیمات پراکسی مرورگر را در دست می‌گیرد و بعد رها می‌کند.
- **تنظیمات پراکسی کل مرورگر:** با فعال شدن این قابلیت، Chrome تنظیمات پراکسی سیستم را کنار می‌گذارد. اگر فیلترشکن شما به صورت System Proxy کار می‌کند، حالت پراکسی را انتخاب کنید و برای بقیه سایت‌ها گزینه دوم را بگذارید.
- **تداخل با افزونه‌های دیگر:** فقط یک افزونه می‌تواند پراکسی مرورگر را کنترل کند. اگر افزونه پراکسی دیگری فعال باشد، پیام قرمز «اعمال نشد» نمایش داده می‌شود.
- **فقط همین مرورگر:** برنامه‌های دیگر سیستم و مرورگرهای دیگر تحت پوشش نیستند. با غیرفعال یا حذف شدن افزونه، این محافظت هم برداشته می‌شود.
- **نشت DNS و WebRTC:** پیش‌واکشی DNS مرورگر ممکن است نام دامنه را از DNS سیستم بپرسد و WebRTC هم از این محافظت عبور نمی‌کند. در حالت پراکسی، با SOCKS4 نام دامنه همیشه محلی resolve می‌شود؛ SOCKS5 را ترجیح دهید.

## 📁 ساختار فایل‌ها

- `manifest.json`: مشخصات و کانفیگ اکستنشن (Manifest V3)
- `proxy.js`: منطق Kill Switch (اعتبارسنجی، ساخت اسکریپت PAC برای حالت تونل و پراکسی، مقایسه IP)
- `inject.js`: هوک Native برای بازنویسی APIهای Geolocation و Intl در World اصلی صفحه
- `content.js`: ارتباط بین حافظه اکستنشن و اسکریپت تزریق‌شده
- `background.js`: سرویس‌ورکر پس‌زمینه برای مدیریت وضعیت، Badge، اعمال تنظیمات پراکسی، تشخیص فیلترشکن و بررسی دوره‌ای IP
- `popup.html` و `popup.js`: رابط کاربری پاپ‌آپ و انتخابگر شهرها
